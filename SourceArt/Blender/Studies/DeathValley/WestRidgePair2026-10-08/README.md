# Western ridge pair sources

Editable sources are `west_ridge01.blend`, `northwest_ridge01.blend`, `combined01.blend` and `Pilot01.blend`, constructed with Blender 5.2.2 LTS using metre units, the fixed projected origin and packed geographic imagery.

Individual sections have 256 meshes with 2 m interior controls and complete 1 m borders. The combined review has 3,072 meshes with 4 m interiors and full borders. Existing section references are protected from selection. Immutable resources and native reopen proofs are under `SourceData/Terrain/DeathValley/WestRidgePair2026-10-08/Prepared01/` relative to the checkout root.

The [implementation receipt](../../../../../Docs/DeathValley/WEST_RIDGE_PAIR_IMPLEMENTATION_2026-10-08.md) records source provenance, bounds, visual evidence, verified exports and native Unity handoff. These editable sources remain outside Unity's import boundary; playable ground uses exported heights/imagery and native TerrainData.
