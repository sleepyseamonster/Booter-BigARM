# Next west and northwest Blender sources

Accepted editable sources: `west_next01.blend`, `northwest_next01.blend`, `combined01.blend` and `Pilot01.blend`. All were built, saved and reopened with Blender 5.2.2 LTS on D:, using metre units, the existing projected origin and packed geographic imagery.

The two full sections each have 256 meshes at 2 m interior spacing and complete 1 m borders. The combined 2,048-mesh review has 4 m interiors and complete 1 m borders. Retained references are protected from selection. Reopen proofs and immutable preparation are in `SourceData/Terrain/DeathValley/NextWestPair2026-10-08/Prepared01/` relative to the checkout root.

Use [the implementation receipt](../../../../../Docs/DeathValley/NEXT_WEST_PAIR_IMPLEMENTATION_2026-10-08.md) for geographic bounds, source provenance, render evidence, export contracts and native Unity validation. These `.blend` files are authoring sources; the guarded height/imagery export supplies native Unity Terrain rather than importing Blender meshes as playable ground.
