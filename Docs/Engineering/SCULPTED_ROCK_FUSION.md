# Sculpted rock fusion — October 10, 2026

The author wants overlapping sculpted rocks to become one continuous mesh, retain readable corner creases where the surfaces meet, and remove buried internal faces. The latest October 10 direction returns to explicit **Fuse Selected Rocks**: automatic live fusion is off by default on existing and new sculpted-rock prefabs. A reversible Edit Mode preview remains available as an optional toggle. Joining or Unity mesh combining alone does not remove buried faces.

## Use

1. Arrange the sculpted rocks, select their overlapping root objects, then click **Fuse Selected Rocks** in the fusion panel. Existing/new sculpted-rock prefabs default to manual fusion. The finished mesh/prefab is persistent, preserved sources are disabled with Undo support, and saving the scene keeps the baked arrangement.
2. For optional live preview, enable **Live Fusion** on participating rocks. Existing linked copies inherit prefab defaults; new sculpted-rock prefabs in the established Environment/Sculpted lane are registered on import with live preview off. The component can also be added manually to another imported rock root.
3. In optional live mode, move, rotate or scale the original roots. Overlapping rocks in the same scene and with the same **Fusion Set** form a connected group. After movement settles for about 0.35 seconds, a background Blender process rebuilds its exterior. Processing adds a short delay; this is not frame-rate CSG while dragging.
4. Live sources remain active, their transforms and colliders remain editable, and their normal renderer-enabled settings are retained. Only `forceRenderingOff` is temporarily used to display the fused exterior instead. Select sources in the hierarchy or through the Inspector's **Edit [rock name]** buttons. Clicking the preview selects a source.
5. Move a live source again and the old preview is removed at the next 0.15-second scan. Pull sources apart and normal rendering is restored. Disable Live Fusion or use different Fusion Set numbers to keep them separate.

The transient live preview is omitted from scene saves and builds; source transforms and the membership component are saved normally. Entering Play Mode, reload, scene close, or Undo clears previews and restores rendering; Edit Mode rebuilds afterward. Runtime uses authored sources until an explicit final bake is chosen. Preview colliders are not installed; source colliders remain the editing geometry. The installed Blender path is configured in the fusion panel or `BOOTER_BLENDER_EDITOR`.

One output MeshRenderer uses the original material slots. Different saved URP Lit texture sets, including Basalt01 and Basalt02, retain their own UVs and slot assignments in one mesh; this is not a one-draw-call atlas optimization. UVs and source corner normals are interpolated through the Boolean cuts, and identical output corners are welded only when their positions, normals and UVs match. Source tangents and handedness are also interpolated and retained, so baked normal maps keep their original texture basis. Missing input tangents are calculated on a temporary mesh copy. Thus each source's surface shading survives while normals can remain discontinuous at the meeting edges. This produces hard join creases where the two surfaces have different directions; flush or fully buried surfaces do not invent a groove. There is no smoothing-union blend or bevel that rounds away the authored shapes.

The output mesh and prefab are under `Assets/_Project/Art/Environment/Rocks/Fused/`, keyed by input geometry/material and the Blender version. A small `.fusion.json` report records topology, join-edge and buried-face counts. Raw job snapshots/results stay in ignored `Logs/RockFusion/`. No native `.blend` is edited or published.

## Geometry and failure gates

`Tools/Art/Blender/fuse_rock_meshes.py` uses the installed Blender 5.2.2 Exact solver. It welds UV-split input positions for solid operations while retaining loop UVs and normals. Source face provenance identifies join edges. It verifies closed topology, positive volume, no loose or degenerate geometry, and one connected result. Buried-face checks sample each tessellated surface triangle against the original solids, using boundary tolerance and three-ray parity for inside classification. A polygon's vertex average is unsuitable here because it can lie outside a concave polygon.

The bake rejects open meshes, disjoint/touch-only rocks, unsupported shaders or transient materials, mirrored/zero transforms, more than 16 roots or over 100,000 input triangles. It is bounded to 120 seconds and can be cancelled. Live previews queue one worker at a time. Failed groups keep their source rocks visible and report the problem in the participant Inspector; changing a pose retries. Missing Blender or lost corner attributes fail visibly. Source changes during a bake discard the result before scene changes; closing the tool or a domain reload cancels its task-owned worker. Mesh combining is never silently substituted for a failed union. Protocol/cache version 2 adds per-face material provenance.

Boolean cutting can introduce new triangles even while removing interior surfaces. It is not a minimum-poly retopology operation. In the actual two-basalt fixture, 1,964 source triangles produce 1,840 union triangles, with 178 join edges, one closed component and zero sampled buried faces. Reduction, new LOD generation and optional seam bevel/rebake are separate future asset passes. The current merged asset has one display mesh and a static concave MeshCollider using that same surface. Do not attach a dynamic Rigidbody to it; moving/dynamic collision requires its own convex decomposition.

## Integration contract

This is authored asset creation, not a runtime dressing generator. A content fingerprint caches the bake; it is not a generated-world object ID. Deterministic placement and stable generated-object identities remain the dressing owner's responsibility. Greater Wasteland terrain remains fixed and always loaded, with no terrain or dressing-cell streaming changes here. If later placement cells unload/reload, they should reuse the same baked prefab from their placement record. Authored input selection, transforms, overlap and material are explicit constraints. Original scene sources and the fused instance are preserved through scene serialization and Undo; gameplay runtime deltas and saved-world schemas are untouched.

The older `RockFusion/TopDown3DManifoldNative` implementation remains a macOS-only editor reference. No package, native library or runtime host is changed. The new window only calls the installed Blender from editor code and stores a local executable preference.

## Evidence and limits

Seven focused integration checks run actual background Blender unions: overlapping cubes have the expected analytic volume, disjoint and open inputs are rejected, the author's basalt copies fuse as one closed textured surface, mixed basalt textures retain both submeshes, the final bake/Undo roundtrip passes, and the live preview rebuilds after movement and restores separated sources. The live-save check confirms that preview geometry is absent from serialized scene content. A separate isolated Unity render verifies retained material/UV appearance. Evidence is under `Docs/Evidence/Art/SculptedRockFusion/`; initial version-1 receipts remain historical.

This proves the bounded fixtures and asset workflow; arbitrary self-intersecting sources, all coplanar/tangent degeneracies and high-density performance are not established. The neutral-material mixed-source render confirms a continuous exterior. The textured mixed-source render shows dark face patches despite matching material provenance and source UV interpolation; visual texture quality remains provisional and needs a dedicated atlas rebake/quality pass. Combining material slots into a single atlas also requires that deliberate rebake. No production population, source sculpt overwrite, gameplay smoke test or foreground activation occurs in this implementation.

Technique sources: [Blender Boolean Union](https://docs.blender.org/manual/en/latest/modeling/modifiers/generate/booleans.html) removes interior faces and documents closed-manifold requirements and solver tradeoffs; [Blender baking](https://docs.blender.org/manual/en/latest/render/cycles/baking.html) supports the later high-to-low/atlas handoff when materials or UVs need rebuilding.
