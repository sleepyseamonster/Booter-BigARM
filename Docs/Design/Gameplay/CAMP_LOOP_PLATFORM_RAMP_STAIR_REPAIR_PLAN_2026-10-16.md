# Camp Loop platform, ramp and stair repair

## Audit

The author reports animation freezing after landing on grid platforms and unreliable ramps/stairs. A read-only audit of the current saved Camp Loop found twelve stations and 254 solid colliders. Eleven station roots and 240 colliders lack the ground marker; the original station authoring marks only AP02. The normal ground probe, jump contact collection and landing forecast require that marker. A physically colliding deck can therefore remain logically airborne, retaining the fall action and its busy/input lease indefinitely. The native-ground animation continuation also requires eligible support. A second audit found 39 additional unmarked static solids outside the stations, including the seven camp rocks, ironstone, the resource cache and workshop fixtures; the same freeze can occur there.

The ordinary Rigidbody motor has slope projection and gravity cancellation but no bounded stair-step resolver. Stair risers are 0.25 m high. Descending near a floor can also hover because horizontal movement requests zero vertical speed while the ground probe still reports a floor below. The ground probe selects one sphere-cast candidate before confirming its true face normal, so an edge/riser can hide another valid support. Its fixed eight-hit buffer can saturate. Finally, completed-motion observation rebases on each collider identity, interrupting travel/cadence observations and resetting the standing pose envelope when crossing separate stair treads in the same static station. The clock retains accumulated cycles, but those repeated interruptions can still look like animation stutter.

The animation fallback already advances baseline gait phase; the native foot solver already retains the source pose when reach is unavailable. Preserve these fallbacks rather than expanding pose qualification or relaxing anatomical limits. No additional animation downloads are needed for the identified support/controller faults.

## Implementation plan

1. In the existing Camp Loop session preparation, register active solid static colliders in its existing Camp Loop scene and player ground mask as ground, covering stations/approaches and the audited camp rocks/workshop fixtures. Do this before actor startup, idempotently, at runtime. Exclude triggers, disabled geometry and colliders with attached Rigidbodies. Keep registration scoped to the existing session/scene; preserve authored assets, GUIDs and scene bytes.
2. Select the nearest **valid walkable true face** from ground-probe candidates, rather than abandoning support after one unusable edge. Grow bounded nonallocating query buffers when saturated, and use a separate true-normal ray buffer so nested queries cannot overwrite candidates. Keep slope, mask, self-exclusion and owner rules.
   The audit also found six movable test-prop colliders. Physical ground/contact and jump forecasts must accept these existing Camp Loop Rigidbodies independently of static animation qualification. They remain excluded from static registration, step correction and completed-distance/foot adaptation, using the existing animated fallback. A landing on a movable prop must release the fall action and permit another jump.
3. Treat adjacent static colliders in one registered station as a continuous gait observation group. Keep the actual collider and matrix for support/pose validity. Moved geometry, unregistered/foreign support, flight, teleports, invalid samples and resets still rebase. Do not change the pure tracker's default identity behavior or accepted gait clocks.
4. Add a bounded standing Camp Loop step resolver to the existing motor. Ascend only an encountered low riser with a walkable top within the probe/step height (at most 0.28 m), a clear standing capsule and a clear raised forward path. Snap down only to a nearby confirmed support within that same bound while already grounded. Reject taller obstacles, gaps, steep surfaces, ceilings, triggers, moving props and foreign action ownership. The existing Rigidbody remains the sole movement owner; retain input direction, planar speed and facing. Jumping remains required for the half-metre and taller fixtures.
5. Verify platform landing support and action release, walk/run/LT movement on decks and ramps, stair ascent/descent geometry and gait continuity, narrow edges, mixed/overlapping supports, low ceilings, high ledges, moving/disabled objects, pause/reset and jump/dodge handoffs. Use focused EditMode query/controller/pose tests in the marked hidden candidate. Do not enter author Play Mode or run gameplay smoke tests.
6. Seal exact changed-code, source and protected hashes; run affected motor, jump/airborne, presentation, directional, native-ground, turn, dodge, posture and reset regressions. Import verified task code through the existing author Editor only in stable Edit Mode. Verify valid bindings, successful compilation, unchanged scene/terrain/gait assets and selected main Camp Loop configuration. Commit only task files on main, then hand over feel testing.

## Plan audit and limits

- Ground registration must happen before physics/player startup and must be independent of the order in which individual station components awaken. Registration must stay in the existing Camp Loop scene and player ground mask; it cannot affect other scenes or promote movable props to static ground.
- Step clearance must consider all solid blockers, including marked ground geometry. An endpoint check must not permit crossing a ceiling or a blocked raised path. A rejected step leaves the motor/collision response intact.
- Downward adhesion must not manufacture a landing, consume jump buffers, move airborne/action-owned actors, bridge a missing floor or suppress an actual fall. Sphere-cast normals alone are insufficient at corners; true face normals remain authoritative.
- Collider grouping is transient observation continuity, not saved world identity. Matrix checks and physical distance limits remain mandatory. Accepted straight gaits, speeds, cadence/contact maps, jump gravity/launch, dodge tuning and LT controls remain unchanged.
- Capture the completed Rigidbody position at fixed-tick entry, before bounded step corrections. The observation callback still runs after support resolution, but its distance input must remain completed physics travel. A commanded vertical correction must not create gait distance or a false turn on a sloped support.
- The existing 40-degree animation adaptation bound and 48-degree motor slope bound are separate contracts. Geometry outside pose reach retains the accepted source pose; no higher qualification is inferred from movement support.
- Unity's EditMode physics simulation does not deliver ordinary collision callbacks. Do not describe offline queries or injected completed contacts as a Play Mode landing run. [Unity 6.4 API reference](https://docs.unity3d.com/6000.4/Documentation/ScriptReference/PhysicsScene.Simulate.html).
