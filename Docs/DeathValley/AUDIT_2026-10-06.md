# Death Valley tool audit

The October 6 audit improved the terrain inventory and source-verification tools without changing terrain, Unity assets, gameplay, package versions or procedural-generation design. Further coordination with other agents ended at the user's request.

| Finding | Correction | Proof |
| --- | --- | --- |
| A saved assessment made the atlas claim local verification even when ignored source files were missing | Validate the assessment geography and evidence, then check all five local artifact paths/hashes. Missing files retain a historical verification state; changed files fail the audit. | Fresh-clone, missing-file, wrong-bound, altered-checksum and failed-border regressions |
| Source acquisition depended on input order and silently labeled an unknown product as the eastern tile | Require both known official products, reject duplicates/mislabeled URLs, and order them by geographic identity | Reversed-order and invalid-product regressions |
| An incomplete source acquisition could be overwritten, and the tool offered no usable output-selection argument | Add `--output`, reserve a fresh diagnostic directory, and reject existing directories before network or source writes | Partial-acquisition preservation and output-boundary regressions; existing-directory CLI rejection |
| Cached park geometry was not validated, and refreshed geometry was saved before terrain checks completed | Validate park identity, CRS, completeness and closed finite polygon rings on every read; defer publishing a refresh until source checks pass | Boundary corruption regressions and successful cached-boundary audit |
| A shifted terrain provenance rectangle or changed row orientation could still pass export hash checks | Compare bounds/CRS/encoding/counts/source identity with the terrain contract, and compare focus tiers with configuration | Shifted-bound/reversed-row regression and complete live inventory rerun |
| The atlas led with full technical JSON and concealed interactive children behind an image accessibility role | Show a concise coverage/source summary, retain full records in a disclosure, use an accessible map group, and label the current Greater Wasteland scene | Seven headless browser checks, including keyboard use, missing-file messaging, disclosure and mobile overflow |

**11 offline regression tests passed.** The refreshed inventory again passed all 512 source-file hashes, 480 common-sample border pairs, and saved scene/TerrainData reference checks. All five retained west candidate source artifacts still match their recorded hashes. No source data was downloaded again.

The existing Windows build safeguards were reviewed and left intact. Prior focused Unity tests, Development Player packaging and routing validation remain the evidence recorded in [VERIFICATION.md](./VERIFICATION.md); this audit did not rerun or strengthen their runtime claims. Player performance and user-owned traversal remain pending. No gameplay smoke test was run.

Browser screenshots are local ignored diagnostics under `Logs/DeathValleyAudit/`. The atlas was inspected at desktop and mobile sizes, with zero JavaScript errors and no page overflow. Python syntax, report parsing, relative documentation links and scoped Git whitespace checks also passed before committing the audit.
