## Implemented path

`WorldCliffFacePlanner` links reciprocal absolute-grid candidates only when canyon parent, strata, direction, facing, and rim/toe elevations agree. The existing chunk decorator owns only spans whose first section lies in that chunk. A closed 12-point ring mesh gives the face two stepped strata ledges and a cap; a lower-detail closed mesh supplies collision. The parent and strata key set a stable layer phase. Sparse buttresses and toe fragments load the existing baked `CliffStone_A-E_LOD0-2` Workbench meshes, use LOD groups and simplified box collision, and remain children of the streamed chunk. Spawn, formation, site, approach, route, slope, and chunk-footprint screens limit placement. Static geology writes no save delta.

## Adaptive far streaming candidate, 2026-09-29

The isolated mirror now has a [worker-side adaptive planner](AdaptiveFarStreamingPlanner.cs.txt), [far-landscape integration patch](AdaptiveFarLandscapeIntegration.patch), and [world scheduler patch](AdaptiveFarWorldSchedulerIntegration.patch). Each far tile first presents its original 17×17 mesh. A canyon-containing tile retains an immutable snapshot of canonical vertex positions, normals, and material colors; after near terrain and decoration queues drain, one background task at a time samples and triangulates its high-error cells. The main thread uploads the returned arrays and swaps the visible mesh. Per-cell triangle ranges preserve adaptive detail when near/middle coverage hides or restores parts of a tile. Pending work is cancelled on unload or a busy near window. Static far geometry has no collider or saved runtime delta. The tile key and canonical query/material samples determine the mesh; the selected cells use a stable error and cell-index tie break.
