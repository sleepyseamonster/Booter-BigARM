# Sable Working Files

Create a dated folder such as `YYYY-MM-DD-topic/` for each art task. Save the brief, reference manifest, visual review, small review images when appropriate, and handoff together. Record provenance, proposal/approval status, and links to source and production files.

This is a working-document area. Keep editable production art in the established source-art lane and imported runtime assets under `Assets/_Project/`. Keep large temporary renders and diagnostics in an appropriate ignored local output location and identify their paths in the review; do not duplicate an asset library here. Never place local-only `.blend` sources or terrain source archives in a tracked review batch.

Move accepted shared guidance into its canonical topic-owned document when authorized and leave a pointer here. Preserve versioned comparisons until their retention or removal is explicitly decided.
