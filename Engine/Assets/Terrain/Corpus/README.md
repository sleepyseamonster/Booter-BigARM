# Representative terrain corpus

These files are technical inputs for terrain architecture, diagnostics and regression checks. They are not accepted geography, final terrain recipes or permanent landscape content.

- `manifest-v1.json` fixes the first source/revision/temporal contract.
- `representative-v1.json` names the minimum terrain and traversal cases the production system must eventually generate and query.

The cases deliberately include open ground, ridges, fossil drainage, layered rock, formations, loose material and one bounded non-heightfield wall domain. Movement thresholds and final art remain later authored data.
