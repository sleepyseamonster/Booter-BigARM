# Calibration character source

`character.glb` is a repository-owned technical proxy generated by
`Tools/make_character_fixture.py`. Its simple humanoid blocks, seven joints and
idle/walk clips carry no final character appearance or game-world canon. It uses
meters, right-handed Y-up coordinates, explicit normals/UVs/tangents and up to two
weighted influences at the hip/torso connection. There is no third-party art.

Regenerate from the repository root with `python3 Engine/Tools/make_character_fixture.py`.
Cook with `Engine/build/foundation/engine_model_cook Engine/Assets/Models/Calibration/character.glb Engine/out/models/calibration`;
the output directory must be new. `model.json` and `mesh.bin` are engine-owned runtime data.
