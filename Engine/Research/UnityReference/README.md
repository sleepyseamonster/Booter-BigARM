# Unity research reference library

Collected 2026-09-10. These are historical references, not engine requirements or proof of native implementation. All original Unity documents remain in place. Exact snapshots retain their original wording and links; use this index to navigate the copies. Links inside snapshots may lead to the original Unity area or to historical paths.

Current authority: [engine direction](../../Docs/DIRECTION.md), [master plan](../../Docs/FOUNDATION_PLAN.md), [status](../../Docs/STATUS.md). Old top-down/2D, canyon-first, Unity API, project constants and approval instructions do not override those documents.

**Start here:** [LOD, meshing and Crimson Desert guide](./TRANSFER_GUIDE.md) and [current Unity-to-native visual audit](./ENVIRONMENT_METHODS_AUDIT.md).

This collection contains 65 files: 59 document snapshots, two superseded Git versions and four recovered conversation research notes. [Manifest](./manifest.json) records sources, hashes, recovery transformations, searched scope and exclusions. External-source availability and license claims are historical, not newly verified.
