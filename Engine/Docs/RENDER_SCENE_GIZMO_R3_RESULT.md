# R3 — render snapshots and Scene View manipulation contract

Implemented 2026-09-15 under the [correction plan](./ENGINE_CORRECTION_PLAN.md). This closes A06 and A07 at the engine boundary and connects R2-authored source scenes to the production renderer. [Evidence](../Evidence/R3-render-scene/result.json) binds the focused native checks, shader/source hashes and Metal comparison capture. **R4 shared play lifecycle, streaming recovery and deliberate saves is next.** The visible move/rotate/scale handles and physical mouse acceptance remain the UI owner's explicit open gate.

## Delivered rendering path

`engine_scene_domain` now owns scene data and manipulation math without transport or GPU dependencies. `engine_authoring` adds the live command host and local transport. `engine_render_scene` consumes only the domain module, so the standalone player does not inherit the authoring socket/editor dependency. The Workbench alone opts into both the authoring host and authored-scene rendering.

`RenderSceneSnapshot` extracts one immutable scene revision using its indexed entities and cached affine world matrices. Each draw carries entity identity, full affine and inverse-transpose normal matrices, transformed bounds, typed mesh/material records and shared resource leases. Catalog replacement cannot retire an asset referenced by an in-flight snapshot. Hidden entities are omitted. Unsupported or unresolved identities return entity-specific errors; optional diagnostic mode renders a labelled magenta diagnostic cube instead of silently substituting a production binding.

The initial renderer bindings are the engine cube, sloped solid and sphere plus scalar base color/roughness/metallic materials. This makes live R2-created source entities visible without cooking permanent game content. Imported arbitrary mesh/texture residency expands through the same catalog contract; R5 owns the complete generic textured static/skinned material path and resource budget. Renderer, physics and platform handles do not enter source documents or snapshots.

Affine matrices and transformed bounds now replace the authored path's former yaw/offset/scale assumption. Mirrored transforms flip culling consistently in color, prepass and shadow passes. Shared per-draw setup binds the model, inverse-transpose normal, linear tangent and determinant sign before every color or depth/normal submission. The vertex shaders transform tangents with the linear matrix, orthogonalize them against the transformed normal and correct handedness under reflection. Static and skinned shaders share this contract. The glTF importer preserves supplied tangents; when UV0 exists without tangents, it computes a UV-derived accumulated tangent/bitangent basis and handedness. Assets that request normal mapping without UV0 and compatible tangents reject or diagnose explicitly.

`RenderViewportRegistry` assigns each viewport unique scene/display view IDs, dimensions and target generation. The focused contract proves two viewport records resize and retire independently. The production Workbench currently renders its Scene View through the existing scene/display target. R4 supplies the second live Game View session and its GPU target; this result does not claim that Game View already exists.

## Selection and manipulation

`pickRenderScene` intersects a world ray with each draw's transformed local mesh bounds and returns the nearest deterministic entity. `SceneGizmoSession` pins scene ID, source revision, selection and original world matrices at drag start. Move, rotate and scale support world/local spaces and optional snapping. Updates are absolute from drag start and produce ephemeral affine overrides only; they never enqueue per-frame source edits.

Release emits one `set_world_transforms` operation through the same validated scene transaction used by AI authoring. Parent/child multi-selection uses the R1 parent-aware conversion, preventing a parent's motion from being applied twice. One completed drag creates one undo entry. Escape, focus loss or explicit cancel discards preview state without touching the source. A concurrent AI/human edit makes the expected revision stale, closes the drag and reports a conflict rather than silently rebasing it. The [UI handoff contract](../UIUX/GIZMO_ENGINE_CONTRACT.md) specifies picking, selection, preview, commit/cancel and viewport ownership for the visible widget implementation.

## Verification and limits

Four focused native suites pass: R1 scene corrections, R2 bounded hosting, the new render-scene/gizmo contract and model import/animation. The new suite independently checks affine matrices and asymmetric transformed bounds, local-bounds ray picking, missing-asset diagnostics, asset lease survival after catalog replacement, two independent viewport records, parent-aware multi-selection, local axes, snapping, one-step undo/redo, focus cancellation, shared adapter submission and concurrent-edit conflict. Model import now verifies a real UV-bearing source with its tangent attribute removed produces a UV-derived basis rather than the old arbitrary normal basis.

The real Workbench and Metal shaders build. The existing non-focusable technical renderer ran seven captures with zero callback errors. Its authored comparison contains a rotated, nonuniform mirrored cube and a rotated/nonuniform sloped solid through the production color, shadow and contact depth/normal passes. Reversing authored submission order produced byte-identical 1920×1280 PNGs, hash `b7e8cdeaf511455ca8c138ca5f624467b2cd48605fe565ecc85d689ff95f1eda`. The comparison capture was visually inspected and both authored objects are present and lit. Evidence records source, shader binary, configuration and capture hashes.

This proves Mac/Metal source-to-render wiring and the engine-side gizmo behavior. It does not prove visible gizmo controls, physical pointer feel, arbitrary imported GPU asset residency, a second live Game View, Windows/D3D11, gameplay, input-to-photon latency or production performance. No gameplay smoke test ran. The known `BoundedJobs.h` indentation warning remains unrelated. No world generator, seed, stable generated-object identity, authored constraint, chunk residency or persisted runtime delta changed; this batch operates on authored source snapshots only.
