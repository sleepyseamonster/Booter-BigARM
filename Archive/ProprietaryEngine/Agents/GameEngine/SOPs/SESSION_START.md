1. Read `../AGENTS.md`, `../../AGENTS.md`, `../../Docs/DIRECTION.md`, and `../../Docs/STATUS.md`.
2. Inspect `git status --short`; treat existing changes as owned unless explicitly in scope.
3. Run `python3 ../../Tools/check_workspace.py` and `python3 ../../Tools/check_engine_plan.py` when the task touches engine documentation, planning or routing.
4. Select one coherent ready package from `../../Docs/ENGINE_ROADMAP.json`. Do not broaden the task because adjacent work is interesting.
5. Record the target result, allowed paths, source of truth, proof required and stop condition before editing.

For handoff, record the exact changed paths, commands and results, evidence locations, known limitations, and the next ready package. Do not leave an experiment, application or delegate running without saying why.
