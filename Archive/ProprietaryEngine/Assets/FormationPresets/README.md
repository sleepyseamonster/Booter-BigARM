# Native formation presets

Four generator-v4 starting points translated from Unity composition roles:
Braced Outcrop, Scattered Stones, Layered Pile and Low Ridge. These are editable
native recipes, not copies of the Unity baked meshes. Detail 1 and eight members
fit the authoring budget; the separate streamed recipe uses six members at detail 0.

Open the [formation workbench](../../Docs/UNITY_FORMATION_PARITY_RESULT.md), select
a preset, edit controls and Apply recipe. Save recipe writes the working copy.
The source preset stays unchanged. Seeded generation and source volumes remain
available; individual formation-member editing is a later extension.
