# Native rock art presets

Three version-2 authoring examples: weathered boulder, layered slab and windworn outcrop. Each is deterministic and uses the same recipe schema as the original generator with an explicit `generator_version: 2`. Original version-1 world recipes remain in `../Recipes/`.

See [the rendered collection and instructions](../../Docs/ROCK_SHOWCASE.md). Open them through the workbench's `--rock-library` option; selecting a preset replaces the preview, and saving writes the chosen working recipe path rather than the library source. The library supports up to 32 JSON presets.
