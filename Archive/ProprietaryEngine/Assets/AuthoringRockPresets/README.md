# Native rock authoring presets

Six generator-v5 examples: fractured boulder, broken slab, angular chunk, tapered
shard, braced outcrop and an authored layered pile. The four singles share seed
1729 and a 1.5 m half-size envelope so profile differences are easy to compare.
Singles use detail 2; six-member formations use detail 1 within the existing mesh
budget. These are starting points for editing, not final geological art.

Choose a preset in the [workbench](../../Docs/ROCK_AUTHORING_V5_RESULT.md), edit the
draft, Apply, then Save or Export. The packaged launcher saves to its own UserData;
these library originals remain unchanged. Auto selects formation shapes by role;
a fixed silhouette applies that family to all four seeded mesh variants.

V5 recipes preserve individual member offsets, proportions, yaw, mesh variant and
ground-only seating. Slot identity is retained when editing. Reducing member count
removes edits for slots beyond the new count; Undo restores the accepted recipe.
The live streaming cache currently accepts only v1–v4 recipes.
