# Local wardrobe fitting pilot

Generated technical samples for the privately retained animation-test character. These assets are local-only because their rig contract references the existing ignored `MaleBaseMeshOriginalRig.fbx`. Preserve the asset/meta pairs together. Do not treat them as production equipment or publish derived character geometry without resolving the source boundary.

Open **Booter & BigARM > Wardrobe > Fitting Preview** when ready to inspect. Toggle the texture grid, jacket shell and rigid chest plate; assign an existing Unity AnimationClip and scrub time. The preview creates a disposable scene and does not change inventory or gameplay scenes. Opening is user-controlled; automation does not raise the Editor.

The shell follows the source body's segmented topology. Openings and ragged boundaries remain; it is not an accepted jacket, finished armor set, or an optimized runtime asset. No collider, armor rating, recipe, item slot, material provenance, save field or production installation is established.
